Macで写真の容量を小さくする方法（まとめて・指定サイズ以下に）

2026年11月 · macOS 14以降

Macで写真の容量を小さくするいちばん簡単な方法は、標準のプレビューでファイル → 書き出すを選び、JPEGにして品質のスライダを左へ動かすことです。予想サイズが十分小さくなったら保存します。枚数が多いときはFinderのイメージを変換でまとめて変えられますが、1枚ずつを決まった容量以下に収めることはできません。「すべて1MB以下」のような上限があるなら、上限サイズを決められるアプリが速いです。

応募フォームに「JPG・1MBまで」とあって、写真は20枚。圧縮サイトでもできますが、すべての写真を他人のサーバーにアップロードして、1枚ずつダウンロードし直すことになります。Macならアップロードせずにできます。

1. プレビュー（無料・1〜2枚）

  1. 写真をプレビューで開きます。
  2. ファイル → 書き出すを選びます。
  3. JPEGを選び、品質のスライダを左へ動かします。動かすとファイルサイズの予想が変わります。
  4. 上限より小さくなったら保存します。

上限より少し下で止めるのがコツです。品質を下げすぎると文字や顔がぼやけます。保存したファイルを選んで⌘Iを押すと、実際の大きさを確かめられます。

2. Finderのイメージを変換（無料・まとめて）

  1. Finderで写真を選びます。
  2. Controlキーを押しながらクリックし、クイックアクション → イメージを変換を選びます。
  3. フォーマットとイメージサイズを選んで変換します。

すべての写真が一度に変わりますが、選べるのは画素の大きさで、ファイルの容量ではありません。1MBのような上限に入ったかは、1枚ずつ確かめる必要があります。

3. たくさんの写真を決めた容量以下に：Dropfit for Mac

Dropfit for Macは私が作ったアプリです。デスクトップの小さな円にファイルをドラッグすると、選んだ形式で出てきます。

  1. 円をControlキーを押しながらクリックして設定を開き、JPGのプリセットに最大サイズ（例：1MB）を決めます。最初の一度だけです。
  2. 写真、またはフォルダごと円にドラッグし、そのプリセットの上で離します。
  3. どの写真もその容量以下で元のファイルの隣に保存されます。元のファイルはそのままで、ファイルはMacから出ません。

iPhoneの写真（HEIC）もそのまま入れられます。JPGへの変換と容量合わせを一度に行います。決めた容量に収まらない写真があれば、Dropfitが知らせます。プリセットには「応募フォーム 1MB」「ポートフォリオ 500KB」のように名前を付けられ、次からはドラッグするだけです。

アプリの表示言語は、今のところ英語と韓国語です。

よくある質問

Macで写真の容量を無料で小さくするには？

プレビューで開いてファイル → 書き出すを選び、JPEGにして品質のスライダを左へ動かします。動かすと予想サイズが変わるので、上限より小さくなったら保存します。

Macで写真をまとめて小さくできますか？

できます。Finderで写真を選び、Controlキーを押しながらクリックしてクイックアクション → イメージを変換を選ぶと、形式と画素の大きさをまとめて変えられます。ただし1枚ずつを1MBのような容量以下に収めることはできません。

すべての写真を1MB以下にするには？

Dropfit for MacでJPGのプリセットに最大サイズ（例：1MB）を一度決め、写真やフォルダごとそのプリセットに離します。どの写真もその容量以下で元の隣に保存されます。

iPhoneのHEIC写真も使えますか？

使えます。HEICの写真をそのまま入れると、DropfitがJPGに変換して容量合わせまで一度に行います。
