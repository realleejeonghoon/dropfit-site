MacでPDFを結合する方法

2026年11月 · macOS 14以降

MacでPDFを手早く結合するには、Finderでファイルを選び、Controlキーを押しながらクリックしてクイックアクション → PDFを作成を選びます。ページ単位で並べ替えたいときはプレビューを使います。よく結合する方で、順番とファイル名を一度に決めたいなら、小さなアプリが速いです。どの方法もファイルはアップロードされません。

「PDF1つにまとめて送ってください」はよくある依頼です。契約書や身分証のスキャンを、結合のためだけにWebサイトへアップロードするのは気が引けます。Macなら何も入れずにできます。

1. Finderで結合（いちばん速い）

  1. Finderで、まとめたいPDFや画像をすべて選びます。
  2. Controlキーを押しながらクリックし、クイックアクション → PDFを作成を選びます。
  3. 結合したPDFが同じフォルダにできます。

順番を変える画面はありません。順番が大事なときは、先にファイル名の頭に01、02…と付けておきます。

2. プレビューでページを並べる

  1. 最初のPDFをプレビューで開きます。
  2. 表示 → サムネールを選び、左にページ一覧を出します。
  3. 次のPDFをFinderからその一覧の入れたい位置へドラッグします。
  4. 一覧のページをドラッグして順番を変えます。
  5. ファイル → PDFとして書き出すを選び、新しい名前で保存します。

そのまま保存すると、最初に開いた元のPDFが変わります。元を残したいときは「PDFとして書き出す」を使います。

3. 順番と名前を一度に：Dropfit for Mac

Dropfit for Macは私が作っている、デスクトップに円として置かれる小さなアプリです。円のPDFの上にファイルをドラッグすると、1つのPDFになります。

  1. PDFや写真を選び、円のPDFの上にドラッグします。
  2. 順番の画面で、ファイルをドラッグして並べ替えるか、名前順に並べます。上にファイル数と合計ページ数が出ます。
  3. ファイル名を入力してReturnキーを押します。
  4. 結合したPDFが最初のファイルの隣に保存されます。
  • PDFの文字や線はくっきりしたまま。ページはそのままコピーされます。
  • 写真は1枚が1ページになり、元の向きのままです。
  • 名前を空にすると最初のファイル名になります。フォルダごとドラッグするとフォルダ名になります。

PDFの結合は無料で、登録も回数制限もありません。

アプリの表示言語は、今のところ英語と韓国語です。

送る前に

  • 容量の上限があるときは、結合したファイルを選んで⌘Iで大きさを確かめます。スキャンや写真が入るとPDFはすぐ大きくなります。
  • パスワード付きのPDFは、ロックを外してから結合します。
  • 契約書や身分証の書類は、Macの中で結合すれば他人のサーバーに残りません。

よくある質問

MacでPDFを無料で結合できますか？

できます。Finderのクイックアクション「PDFを作成」とプレビューはmacOSの標準機能で、Dropfit for MacのPDF結合も無料です。

写真とPDFを1つのファイルにまとめられますか？

FinderのPDFを作成とDropfit for Macは、写真とPDFを1つのPDFにまとめられます。写真は1枚が1ページになります。

結合すると元のPDFは変わりますか？

FinderとDropfitは新しいファイルを作り、元のファイルはそのままです。プレビューでそのまま保存すると最初に開いたPDFが変わるので、「PDFとして書き出す」で新しいファイルを作ります。
