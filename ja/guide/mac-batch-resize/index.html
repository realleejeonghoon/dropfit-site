Macで画像のサイズをまとめて変更する方法（幅1080pxなど）

2026年11月 · macOS 14以降

Macで画像のサイズを無料でまとめて変える方法は2つあります。Finderで画像を選び、Controlキーを押しながらクリックしてクイックアクション → イメージを変換でサイズ（小・中・大）を選ぶ方法と、プレビューですべての画像を開きツール → サイズを調整で幅をピクセルで入れる方法です。1080pxのように決まった幅を何度も使うなら、幅を一度入れて全部保存できるアプリが速いです。

撮影した写真30枚を、SNS用に幅1080pxにそろえてクライアントに渡す。カメラやiPhoneの写真は幅4000pxを超えることが多く、そのままではアップロードが遅く、サイトの上限にもかかります。変換サイトを使わなくても、Macの中でまとめて変えられます。

1. Finderのイメージを変換（無料・いちばん簡単）

  1. Finderで画像を選びます。
  2. Controlキーを押しながらクリックし、クイックアクション → イメージを変換を選びます。
  3. フォーマットとイメージサイズ（小・中・大・実際のサイズ）を選んで変換します。

新しいファイルが同じフォルダにでき、元のファイルは残ります。ただし1080pxのような数字は入れられません。

2. プレビューのサイズを調整（無料・ピクセルで指定）

  1. 画像をすべて選んでプレビューで開きます。
  2. サイドバーをクリックし、⌘Aですべて選びます。
  3. ツール → サイズを調整を選び、単位をピクセルにして幅を入れます。縦横の比率を保つ設定はオンのままにします。
  4. ウインドウを閉じると変更が保存されます。

プレビューは元のファイルに上書きします。元のサイズも必要なら、先に複製しておきます。

3. 決めた幅でまとめて保存：Dropfit for Mac

Dropfit for Macは私が作ったアプリです。

  1. 画像をデスクトップの円にドラッグし、「N枚を切り抜く」の上で離します。
  2. 切り抜きウインドウでサイズ指定を選び、幅の欄にだけ1080と入れます。高さは比率に合わせて決まります。
  3. 必要なら形式（JPGなど）と最大容量を選び、保存をクリックします。
  4. どの画像も幅1080pxで元のファイルの隣に保存されます。元のファイルはそのままで、ファイルはMacから出ません。

端を切らずにサイズだけ変えたいときは、枠をそのままにして保存します。

Macの言語が日本語なら、アプリも日本語で表示されます（バージョン1.0.1以降）。

よくある質問

Macで画像のサイズを無料でまとめて変えられますか？

できます。Finderで画像を選んでクイックアクション → イメージを変換を使うか、プレビューですべて選んでツール → サイズを調整で幅をピクセルで入れます。

サイズを小さくするとファイルの容量も小さくなりますか？

多くの場合、大きく小さくなります。サイトに容量の上限もあるなら、Dropfitで最大容量を選ぶとその容量以下で保存されます。

縦の写真と横の写真がまざっているときは？

幅だけを入れると、どの写真も自分の比率のままその幅になります。長い辺をそろえたいときは、縦の写真を別にまとめて高さを入れます。
