PDF 합치기: 맥에서 여러 PDF와 사진을 한 파일로

2026년 11월 · macOS 14 이상 기준

맥에서 PDF를 가장 빠르게 합치려면 Finder에서 파일을 모두 선택하고 마우스 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누릅니다. 쪽 하나하나의 순서를 맞춰야 하면 미리보기를 쓰고, 자주 합친다면 순서와 파일 이름을 한 창에서 정하는 앱이 빠릅니다. 세 방법 모두 파일을 인터넷에 올리지 않습니다.

제출 서류를 "한 파일로" 내라는 안내는 자주 나오는데, 계약서나 신분증이 든 파일을 온라인 사이트에 올리기는 망설여집니다. 맥에서는 설치 없이도 합칠 수 있습니다.

1. Finder에서 바로 합치기 (가장 빠름)

  1. Finder에서 합칠 PDF와 사진을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누릅니다.
  3. 같은 폴더에 합쳐진 PDF가 하나 생깁니다.

순서를 바꾸는 화면은 없습니다. 원하는 순서가 있으면 파일 이름 앞에 01, 02처럼 번호를 붙여 두면 안전합니다.

2. 미리보기로 쪽 순서까지 맞추기

  1. 첫 번째 PDF를 미리보기로 엽니다.
  2. 메뉴에서 보기 → 축소판을 누르면 왼쪽에 쪽 목록이 나옵니다.
  3. 합칠 PDF를 Finder에서 그 목록의 원하는 자리로 끌어다 놓습니다.
  4. 목록에서 쪽을 끌어 옮기면 순서가 바뀝니다.
  5. 파일 → PDF로 내보내기를 눌러 새 이름으로 저장합니다.

그냥 저장하면 처음 연 PDF 원본이 바뀝니다. 원본을 남기려면 'PDF로 내보내기'로 새 파일을 만듭니다.

3. 순서와 이름을 한 번에: 드롭핏(Dropfit) 맥 앱

드롭핏(Dropfit for Mac)은 제가 만든 맥 앱입니다. 화면에 떠 있는 동그라미의 'PDF'에 파일을 끌어다 놓으면 PDF 하나로 합칩니다.

  1. 합칠 PDF와 사진을 모두 골라 동그라미의 'PDF'에 끌어다 놓습니다.
  2. 'PDF 합치기' 창에서 파일을 끌어 순서를 바꾸거나 '이름순으로 정렬'을 누릅니다. 위에 파일 수와 전체 쪽수가 보입니다.
  3. '이름' 칸에 파일 이름을 적고 '합치기'를 누릅니다.
  4. 합친 PDF는 첫 파일 옆에 저장됩니다.
  • PDF 안의 글자와 선은 깨지지 않고 그대로 옮겨집니다.
  • 사진은 한 장이 한 쪽이 되고, 사진 방향은 그대로입니다.
  • 이름을 비우면 '첫 파일 외 2장.pdf'처럼 이름이 붙고, 폴더째 끌어다 놓으면 '폴더 이름.pdf'가 됩니다.

PDF 합치기는 무료이고, 가입이나 횟수 제한 없이 사용할 수 있습니다. 'PDF 합치기' 창 없이 바로 합치려면 설정에서 '합치기 전에 순서 정하기'를 끄면 됩니다. 그때는 끌어다 놓은 순서대로 합칩니다.

합치기 전 확인할 것

  • 제출처에 용량 제한이 있으면 합친 파일을 선택하고 ⌘I로 크기를 확인합니다. 스캔본이나 사진이 많으면 커지기 쉽습니다.
  • 암호가 걸린 PDF는 먼저 암호를 풀어야 합칠 수 있습니다.
  • 계약서·신분증처럼 민감한 서류는 온라인 사이트보다 맥 안에서 합치는 쪽이 마음이 편합니다.

자주 묻는 질문

맥에서 PDF 합치기를 무료로 할 수 있나요?

네. Finder의 빠른 동작 'PDF 생성'과 미리보기는 맥 기본 기능이라 무료이고, 드롭핏(Dropfit) 맥 앱의 PDF 합치기도 무료입니다.

사진과 PDF를 섞어서 한 파일로 합칠 수 있나요?

Finder의 'PDF 생성'과 드롭핏은 사진과 PDF를 섞어서 한 PDF로 합칩니다. 사진 한 장은 한 쪽이 됩니다.

합치면 원래 PDF는 바뀌나요?

Finder와 드롭핏은 새 파일을 만들고 원본은 그대로 둡니다. 미리보기는 그냥 저장하면 처음 연 PDF가 바뀌므로 'PDF로 내보내기'로 새 파일을 만듭니다.
