맥북 이미지 변환: HEIC·PNG를 JPG로, 여러 장과 폴더째 바꾸기

2026년 11월 · macOS 14 이상 기준

맥에서 사진 여러 장을 한 번에 바꾸려면 Finder에서 사진을 선택하고 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환을 누릅니다. JPEG·PNG·HEIF 중에서 고를 수 있습니다. 한 장을 화질까지 정해 바꾸려면 미리보기의 내보내기를 쓰고, 폴더째 바꾸거나 PDF를 쪽마다 이미지로 바꾸려면 앱이 빠릅니다. 세 방법 모두 파일을 인터넷에 올리지 않습니다.

아이폰으로 찍은 사진 수십 장을 JPG로 내야 하는데, 한 장씩 열어 내보내다 보면 금방 지칩니다. 맥에는 설치 없이 쓰는 방법이 두 가지 있고, 각각 할 수 없는 일이 있습니다.

1. Finder 빠른 동작 '이미지 변환' (여러 장 한 번에)

  1. Finder에서 바꿀 사진을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환을 누릅니다.
  3. 포맷(JPEG·PNG·HEIF)과 크기를 고르고 변환을 누르면 같은 폴더에 새 파일이 생깁니다.

고를 수 있는 포맷은 JPEG·PNG·HEIF 세 가지입니다. 폴더를 선택하면 안에 든 사진은 바뀌지 않으므로, 폴더를 열어 사진을 직접 선택해야 합니다.

2. 미리보기 '내보내기' (한 장을 세밀하게)

  1. 사진을 미리보기로 열고 파일 → 내보내기를 누릅니다.
  2. 포맷을 고르고, JPEG는 품질 슬라이더로 화질을 정합니다.
  3. 새 이름으로 저장합니다.

한 장씩 화질을 보며 정할 수 있지만, PDF 여러 쪽을 이미지로 바꾸려면 쪽마다 따로 내보내야 합니다.

3. 끌어다 놓기 한 번: 드롭핏(Dropfit) 맥 앱

드롭핏(Dropfit for Mac)은 제가 만든 맥 앱입니다. 화면에 떠 있는 동그라미에 파일을 끌어다 놓으면 포맷이 펼쳐집니다.

  1. 사진·PDF·폴더를 동그라미에 끌어다 놓습니다.
  2. 펼쳐진 포맷(JPG·PNG·HEIC·TIFF·GIF·PDF) 중 하나 위로 끌어다 놓습니다.
  3. 원본 옆에 새 파일이 생기고, 원본은 그대로 남습니다.
  • 폴더째 끌어다 놓으면 안에 든 사진을 모두 바꿉니다.
  • PDF를 JPG에 놓으면 쪽마다 한 장씩 이미지가 생깁니다.

포맷 변환, 폴더째 변환, PDF 합치기는 무료이고 가입이나 횟수 제한이 없습니다.

자주 묻는 질문

맥에서 HEIC를 JPG로 무료로 바꿀 수 있나요?

네. Finder 빠른 동작의 '이미지 변환'과 미리보기의 내보내기는 맥 기본 기능이라 무료이고, 드롭핏(Dropfit) 맥 앱의 포맷 변환도 무료입니다.

변환하면 원본 사진은 어떻게 되나요?

세 방법 모두 새 파일을 만들고 원본은 그대로 둡니다. 드롭핏은 새 파일을 원본 옆에 저장합니다.

웹에서 저장한 WebP 이미지는 어떻게 JPG로 바꾸나요?

미리보기로 열어 파일 → 내보내기에서 포맷을 JPEG로 고르면 됩니다. 여러 장이면 드롭핏에 끌어다 놓고 JPG 위에 놓으면 한 번에 바뀝니다.

폴더 안의 사진을 한 번에 바꿀 수 있나요?

Finder의 '이미지 변환'은 폴더를 선택하면 안의 사진을 바꾸지 않아 사진을 직접 선택해야 합니다. 드롭핏은 폴더째 끌어다 놓으면 안에 든 사진을 모두 바꿉니다.
