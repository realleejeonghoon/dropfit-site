맥에서 이미지와 PDF를 다루는 방법을 정리합니다.

  • 용량 초과로 업로드가 안 될 때: 사진을 1MB·2MB 이하로 줄이는 법

    ‘용량 초과’가 뜨면 확인할 세 가지와 정한 용량 아래로 줄이는 법.

  • 포트폴리오·지원 서류 PDF 용량 제한: 맥에서 한 파일로 합쳐 50MB 아래로

    모집요강의 ‘PDF 1개, 50MB 이하’에 맞춰 서류를 순서대로 합치고 줄이는 법.

  • 맥 사진 용량 줄이기

    한두 장은 미리보기, 여러 장은 Finder나 앱으로. 방법별 가격·여러 장 처리·용량 맞추기 비교.

  • PDF 합치기: 맥에서 여러 PDF와 사진을 한 파일로

    Finder, 미리보기, 앱으로 업로드 없이 합치고 순서와 파일 이름까지 정하는 법.

  • PDF 용량 줄이기: 맥에서 10MB·5MB 제출 기준에 맞추는 법

    미리보기 Quartz 필터와 목표 용량을 정하는 앱, 글자 PDF·스캔본 실제 시험 결과.

  • 맥북 이미지 변환: HEIC·PNG를 JPG로, 여러 장과 폴더째 바꾸기

    Finder 빠른 동작, 미리보기, 앱별로 되는 것과 안 되는 것.

  • 사진 PDF 변환: 맥에서 사진 여러 장을 PDF 한 파일로

    휴대폰으로 찍은 서류를 순서와 이름까지 정해 PDF 한 파일로.

  • PDF JPG 변환: 맥에서 PDF 모든 쪽을 이미지로

    한두 쪽은 미리보기, 모든 쪽은 한 번에.

  • 아이폰 사진 JPG 변환: 맥에서 HEIC를 JPG로 바꾸기

    아이폰 사진이 업로드되지 않을 때, 여러 장과 폴더째 바꾸는 법.

  • PNG JPG 변환: 맥에서 여러 장을 한 번에 JPG로

    투명한 배경이 어떻게 되는지까지.

  • 증명사진 용량 줄이기: 맥에서 500KB·1MB 제출 기준에 맞추는 법

    미리보기로 직접 맞추는 법과 기준을 정해 두는 법.

  • 사진 여러 장 같은 비율로 자르기: 맥에서 1:1·4:5 한 번에

    비율을 한 번만 골라 모든 사진에 같은 틀을 잡는 법.

  • 사진 크기 한 번에 줄이기: 맥에서 여러 장 가로 1080px로

    Finder·미리보기·앱으로 여러 장 크기를 한 번에 바꾸는 법.
