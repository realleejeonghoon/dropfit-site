사진 크기 한 번에 줄이기: 맥에서 여러 장 가로 1080px로

2026년 11월 · macOS 14 이상 기준

맥에서 사진 여러 장의 크기를 한 번에 줄이는 무료 방법은 두 가지입니다. Finder에서 사진을 모두 선택하고 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환에서 이미지 크기(작게·보통·크게)를 고르거나, 미리보기에서 사진을 모두 연 다음 도구 → 크기 조절로 가로 픽셀을 넣습니다. 가로 1080px처럼 정해진 값을 자주 맞춘다면 그 값을 넣고 한 번에 저장하는 앱이 빠릅니다.

아이폰·카메라 사진은 가로가 4000px이 넘어, 블로그·쇼핑몰·메일에 그대로 올리면 느리거나 용량 제한에 걸립니다. 사진을 사이트에 올려 줄이지 않고 맥에서 바로 줄일 수 있습니다.

1. Finder 빠른 동작 (무료, 가장 간단)

  1. Finder에서 사진을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환을 고릅니다.
  3. 포맷과 이미지 크기(작게·보통·크게·실제 크기)를 고르고 변환합니다.

새 파일이 같은 폴더에 생기고 원본은 남습니다. 다만 크기를 1080px처럼 숫자로 정할 수는 없습니다.

2. 미리보기 크기 조절 (무료, 픽셀 지정)

  1. 사진을 모두 선택해 미리보기로 엽니다.
  2. 왼쪽 사이드바에서 ⌘A로 모두 선택합니다.
  3. 도구 → 크기 조절에서 단위를 픽셀로 바꾸고 가로를 넣습니다. '비례에 맞게 조절'을 켜 둡니다.
  4. 창을 닫으면 바뀐 내용이 저장됩니다.

원본 위에 저장되므로 필요하면 먼저 복사해 둡니다.

3. 정한 크기로 저장하기: 드롭핏(Dropfit) 맥 앱

드롭핏(Dropfit)은 제가 직접 만든 맥 앱입니다.

  1. 사진 여러 장을 화면의 동그라미에 끌어다 놓고, 'N장 자르기' 위에 놓습니다.
  2. 자르기 창에서 '크기 지정'을 고르고 가로 칸에만 1080을 넣습니다. 세로는 비율대로 정해집니다.
  3. 필요하면 포맷(JPG 등)과 최대 용량도 고르고 저장합니다.
  4. 모든 사진이 가로 1080px로 원본 옆에 새로 저장됩니다. 원본은 그대로 남습니다.

사진을 잘라 내지 않고 크기만 바꾸려면 틀을 손대지 않고 저장하면 됩니다.

자주 묻는 질문

맥에서 사진 여러 장 크기를 무료로 한 번에 줄일 수 있나요?

네. Finder에서 사진을 모두 선택하고 빠른 동작 → 이미지 변환으로 크기를 고르거나, 미리보기에서 모두 선택한 다음 도구 → 크기 조절로 가로 픽셀을 넣으면 됩니다.

크기를 줄이면 용량도 줄어드나요?

대부분 크게 줄어듭니다. 그래도 제출처의 용량 기준이 있다면 드롭핏에서 최대 용량을 함께 정해 두면 기준 아래로 저장됩니다.

세로 사진과 가로 사진이 섞여 있으면요?

가로 칸에만 값을 넣으면 사진마다 비율을 유지하며 가로를 그 값에 맞춥니다. 긴 쪽을 맞춰야 한다면 세로 사진은 따로 모아 세로 칸에 값을 넣습니다.
