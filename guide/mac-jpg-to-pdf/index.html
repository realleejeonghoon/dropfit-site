사진 PDF 변환: 맥에서 사진 여러 장을 PDF 한 파일로

2026년 11월 · macOS 14 이상 기준

맥에서 사진 여러 장을 PDF 한 파일로 만들려면 Finder에서 사진을 모두 선택하고 마우스 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누릅니다. 아이폰의 HEIC 사진도 그대로 됩니다. 한 장씩 보며 순서를 맞추려면 미리보기를, 순서와 파일 이름을 한 창에서 정하려면 앱을 씁니다. 세 방법 모두 파일을 인터넷에 올리지 않습니다.

재직증명서나 영수증을 휴대폰으로 찍어 두었는데 제출처가 "PDF로 올려 주세요"라고 하면, 사진 여러 장을 PDF 한 파일로 묶어야 합니다. 변환 사이트에 올리기엔 개인정보가 걸립니다.

먼저: 아이폰 사진을 맥으로

AirDrop으로 보내면 HEIC 그대로 와도 괜찮습니다. 아래 세 방법 모두 HEIC 사진을 바로 PDF로 만들 수 있습니다.

1. Finder 빠른 동작 'PDF 생성' (몇 장을 바로)

  1. Finder에서 사진을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누릅니다.
  3. 같은 폴더에 PDF 한 파일이 생깁니다.

순서를 바꾸는 화면은 없습니다. 순서가 중요하면 파일 이름 앞에 01, 02를 붙여 둡니다.

2. 미리보기 (한 장씩 확인하면서)

  1. 사진을 모두 선택하고 미리보기로 엽니다.
  2. 왼쪽 축소판에서 끌어 순서를 바꿉니다.
  3. 축소판을 모두 선택(⌘A)하고 파일 → 프린트를 누른 다음, 왼쪽 아래 PDF → PDF로 저장을 누릅니다.

사진이 많으면 단계가 길어집니다.

3. 순서와 이름을 한 창에서: 드롭핏(Dropfit) 맥 앱

지원서를 낼 때마다 휴대폰으로 찍은 서류 사진 여러 장을 PDF 한 파일로 묶으며, 순서를 맞추고 프린트 메뉴로 저장하는 길을 매번 다시 밟는 게 번거로웠습니다. 그래서 제가 직접 맥 앱 드롭핏(Dropfit)을 만들었습니다.

  1. 사진을 모두 골라 화면에 떠 있는 동그라미의 'PDF'에 끌어다 놓습니다.
  2. 'PDF 합치기' 창에서 끌어 순서를 바꾸거나 '이름순으로 정렬'을 누릅니다.
  3. 이름을 적고 '합치기'를 누르면 첫 파일 옆에 PDF 한 파일이 저장됩니다.

사진과 PDF를 섞어도 됩니다. 이미 있는 PDF 뒤에 사진 몇 장을 붙여 한 파일로 만들 수 있습니다. PDF 합치기는 무료이고 가입이나 횟수 제한이 없습니다.

자주 묻는 질문

아이폰 HEIC 사진도 PDF로 바로 만들 수 있나요?

네. Finder의 'PDF 생성', 미리보기, 드롭핏 모두 HEIC 사진을 JPG로 먼저 바꾸지 않고 바로 PDF로 만듭니다.

사진 순서를 정해서 PDF로 만들 수 있나요?

Finder의 'PDF 생성'은 순서를 바꾸는 화면이 없어 파일 이름 앞에 번호를 붙여 둡니다. 미리보기는 축소판을 끌어 바꾸고, 드롭핏은 'PDF 합치기' 창에서 끌거나 '이름순으로 정렬'을 누릅니다.

맥에서 사진을 PDF로 무료로 바꿀 수 있나요?

네. Finder와 미리보기는 맥 기본 기능이라 무료이고, 드롭핏(Dropfit) 맥 앱의 PDF 합치기도 무료입니다.

함께 보면 좋은 글

  • PDF 합치기: 맥에서 여러 PDF와 사진을 한 파일로
  • PDF 용량 줄이기: 맥에서 10MB·5MB 제출 기준에 맞추는 법
  • 맥북 이미지 변환: HEIC·PNG를 JPG로
