아이폰 사진 JPG 변환: 맥에서 HEIC를 JPG로 바꾸기

2026년 11월 · macOS 14 이상 기준

아이폰 카메라 포맷이 '고효율성'이면 사진이 HEIC로 저장되어, JPG만 받는 사이트에 올리면 막힙니다. 맥에서는 Finder에서 사진을 선택하고 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환에서 JPEG를 고르면 여러 장을 한 번에 JPG로 바꿀 수 있습니다. 앞으로 찍는 사진을 JPG로 받으려면 아이폰 설정 → 카메라 → 포맷에서 '높은 호환성'을 고릅니다.

아이폰으로 찍은 사진을 AirDrop으로 맥에 옮겼는데, 제출 화면에서 "jpg, png만 올릴 수 있습니다"가 뜨거나 받는 사람이 파일을 열지 못하는 경우가 많습니다. 파일 끝이 .heic이면 포맷을 바꿔야 합니다.

먼저: 앞으로 찍는 사진을 JPG로 받으려면

아이폰 설정 → 카메라 → 포맷에서 '높은 호환성'을 고르면 이후에 찍는 사진은 JPG로 저장됩니다. 이미 찍은 HEIC 사진은 아래 방법으로 바꿉니다.

1. Finder 빠른 동작 '이미지 변환' (여러 장 한 번에)

  1. Finder에서 HEIC 파일을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환을 누릅니다.
  3. 포맷을 JPEG로 고르고 변환을 누르면 같은 폴더에 새 파일이 생깁니다.

폴더를 선택하면 안의 파일은 바뀌지 않으므로, 폴더를 열어 파일을 직접 선택합니다.

2. 미리보기 '내보내기' (한 장씩)

  1. HEIC 파일을 미리보기로 열고 파일 → 내보내기를 누릅니다.
  2. 포맷을 JPEG로 고르고 품질을 정합니다.
  3. 새 이름으로 저장합니다.

한 장씩 화질을 보며 정할 수 있지만, 사진이 많으면 같은 과정을 반복해야 합니다.

3. 끌어다 놓기 한 번: 드롭핏(Dropfit) 맥 앱

마감 시간이 얼마 남지 않았을 때, 아이폰으로 찍어 둔 이미지를 맥으로 옮겨 올리려는데 지원하지 않는 형식(HEIC)이라며 올라가지 않았습니다. 변환 사이트에 파일을 하나씩 올리고, 변환시키고, 다시 내려받다가 한 번에 끝내주는 도구로 직접 만든 앱이 드롭핏(Dropfit for Mac)입니다. 화면에 떠 있는 동그라미에 파일을 끌어다 놓으면 포맷이 펼쳐집니다.

  1. HEIC 파일이나 그 파일이 든 폴더를 동그라미에 끌어다 놓습니다.
  2. 펼쳐진 포맷 중 'JPG' 위로 끌어다 놓습니다.
  3. 원본 옆에 새 파일이 생기고, 원본은 그대로 남습니다.

폴더째 끌어다 놓으면 안에 든 파일을 모두 바꿉니다. 포맷 변환은 무료이고 가입이나 횟수 제한이 없습니다.

자주 묻는 질문

아이폰 사진이 업로드되지 않는 이유는 무엇인가요?

아이폰은 카메라 포맷이 '고효율성'이면 사진을 HEIC로 저장하는데, 많은 사이트가 JPG·PNG만 받습니다. 파일을 JPG로 바꾸면 올릴 수 있습니다.

맥에서 HEIC를 JPG로 무료로 바꿀 수 있나요?

네. Finder 빠른 동작의 '이미지 변환'과 미리보기의 내보내기는 맥 기본 기능이라 무료이고, 드롭핏(Dropfit) 맥 앱의 포맷 변환도 무료입니다.

앞으로 찍는 사진을 처음부터 JPG로 받을 수 있나요?

네. 아이폰 설정 → 카메라 → 포맷에서 '높은 호환성'을 고르면 이후에 찍는 사진은 JPG로 저장됩니다.
