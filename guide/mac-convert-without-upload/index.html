드롭핏 가이드

클라이언트 파일, 변환 사이트에 올려도 될까: 맥 안에서 바꾸고 줄이는 법

2026년 11월 · macOS 14 이상

변환 사이트는 보통 파일을 그 회사 서버로 올려 바꾼 뒤 내려받게 합니다. 클라이언트와 외부 공유를 하지 않기로 했거나 출시 전 자료라면 올리지 않는 편이 안전합니다. 맥의 Finder 빠른 동작 → 이미지 변환과 미리보기만으로도 JPG·PNG 변환, 크기 줄이기, PDF로 묶기를 업로드 없이 할 수 있습니다.

출시 전 신제품 사진 30장을 오늘 안에 광고 대행사로 넘겨야 합니다. 받은 파일은 HEIC와 PNG가 섞여 있고, 대행사는 JPG로 보내 달라고 합니다. 검색하면 맨 위에 변환 사이트가 나옵니다. 업로드 버튼을 누르려다 멈춥니다. 계약서에 있던 '외부 공유 금지' 한 줄이 떠오르기 때문입니다.

브랜드 시안을 납품하는 1인 디자이너, 출시 전 광고 소재를 다루는 마케터, 고객 얼굴이 담긴 촬영본을 정리하는 스튜디오가 자주 겪는 일입니다. 한두 장이면 디자인 앱을 열어 다시 내보내면 되지만, 마감 앞에서 수십 장을 하나씩 하다 보면 결국 사이트에 올리고 싶어집니다.

업로드하면 파일은 어디를 거치나요

웹 변환 사이트는 보통 파일을 서버로 보내 처리하고, 결과를 다시 내려받게 합니다. 처리 뒤 몇 시간 안에 지운다고 안내하는 곳이 많지만, 보관 기간과 서버 위치는 서비스마다 다르고 각 사이트의 개인정보 처리방침에 적혀 있습니다. 클라이언트와 비밀 유지 약속을 했다면 올리기 전에 그 약속부터 확인하는 편이 안전합니다.

1. 형식 바꾸고 크기 줄이기 (Finder 빠른 동작)

  1. Finder에서 바꿀 사진을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → 이미지 변환을 누릅니다.
  3. 형식(JPEG·PNG·HEIF)과 이미지 크기(작게·중간·크게·실제 크기)를 고르고 변환을 누릅니다.

새 파일은 원본과 같은 폴더에 생기고 원본은 그대로 남습니다. '메타데이터 보존'을 끄면 촬영 위치·기기 같은 정보를 빼고 넘길 수 있습니다.

2. 화질을 정해 내보내기 (미리보기)

  1. 사진을 미리보기로 엽니다. 여러 장이면 모두 선택한 채 엽니다.
  2. 사이드바에서 모두 선택한 뒤 파일 → 선택한 이미지 내보내기를 누릅니다.
  3. 포맷과 품질 막대를 정하고 저장할 폴더를 고릅니다.

올리는 곳의 용량 한도가 정해져 있으면 품질 막대를 옮기며 저장해 보고 용량을 확인하는 과정을 몇 번 거치게 됩니다.

3. 시안·사진을 PDF 한 파일로 (Finder 빠른 동작)

Finder에서 파일을 모두 선택하고 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누르면 같은 폴더에 PDF 한 파일이 생깁니다. 순서는 파일 이름 순이라 앞에 01, 02를 붙여 두면 편합니다.

4. 이런 일이 잦다면: 드롭핏(Dropfit) 맥 앱

제가 직접 만든 맥 앱 드롭핏은 파일을 처음부터 맥 밖으로 보내지 않습니다. 사진이나 폴더를 화면의 동그라미에 끌어다 놓고 JPG·PNG·PDF 칸에서 놓으면 원본 옆에 새 파일이 생깁니다. 형식 변환과 PDF 합치기는 무료이고, 올리는 곳 용량 아래로 맞추는 칸은 Pro입니다.

올리는 곳마다 용량 한도가 달라 매번 다시 줄이고 있다면 업로드 용량 초과 글을 참고하세요.

넘기기 전 확인할 것

  • 촬영 위치·기기 정보를 남겨도 되는지 정합니다. 남기지 않으려면 1번에서 '메타데이터 보존'을 끕니다.
  • 파일 이름에 클라이언트 이름과 버전을 붙이면 다시 보내 달라는 연락을 받아도 헷갈리지 않습니다.
  • 원본 폴더는 따로 두고, 바꾼 파일만 압축해 보냅니다.

자주 묻는 질문

변환 사이트에 올린 파일은 지워지나요?

서비스마다 다릅니다. 처리 뒤 일정 시간이 지나면 지운다고 안내하는 곳이 많지만, 보관 기간과 서버가 있는 나라는 각 사이트의 개인정보 처리방침에서 확인해야 합니다.

인터넷이 막힌 사내망 맥에서도 바꿀 수 있나요?

네. Finder 빠른 동작과 미리보기는 인터넷 없이 됩니다. 드롭핏도 변환에 인터넷이 필요 없습니다.

사진의 촬영 위치 정보도 빼고 넘길 수 있나요?

Finder 빠른 동작의 이미지 변환에서 '메타데이터 보존'을 끄고 변환하면 됩니다. 원본에는 정보가 그대로 남습니다.

드롭핏도 파일을 서버로 보내나요?

아니요. 바꾸는 일은 모두 맥 안에서 하고, 파일과 파일 이름은 어디에도 보내지 않습니다. 업데이트를 확인할 때 쓴 횟수 같은 숫자만 보내며, 설정에서 끌 수 있습니다.

함께 보면 좋은 글

  • PDF 합치기: 사이트에 올리지 않고 내 컴퓨터에서 합치는 법
  • 맥북 이미지 변환: HEIC·PNG를 JPG로, 여러 장과 폴더째 바꾸기
  • 용량 초과로 업로드가 안 될 때: 사진을 1MB·2MB 이하로 줄이는 법
