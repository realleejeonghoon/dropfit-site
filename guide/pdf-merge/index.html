PDF 합치기: 사이트에 올리지 않고 내 컴퓨터에서 합치는 법

2026년 11월 · 맥(macOS 14 이상)·윈도우

PDF 합치기 사이트는 편하지만, 합치려면 파일을 그 회사 서버로 올려야 합니다. 맥을 쓴다면 설치 없이 Finder에서 파일을 모두 선택하고 마우스 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누르면 그 자리에서 PDF 하나로 합쳐집니다. 윈도우라면 인터넷 없이 동작하는 PDF 프로그램을 쓰면 파일이 밖으로 나가지 않습니다.

지원서·계약·보험 청구처럼 "PDF 한 파일로 내 주세요"라는 안내를 받으면 대개 검색창에 'PDF 합치기'를 치고 맨 위 사이트를 엽니다. 그런데 그때 합치는 파일은 주민등록등본, 신분증 사본, 통장 사본, 성적증명서처럼 남에게 보이고 싶지 않은 서류인 경우가 많습니다.

PDF 합치기 사이트에서 일어나는 일

  1. 내 PDF가 인터넷을 거쳐 사이트의 서버로 올라갑니다.
  2. 서버가 파일을 합쳐 새 PDF를 만듭니다.
  3. 합친 파일을 다시 내려받습니다. 원본과 결과물은 정해진 시간 동안 서버에 남을 수 있습니다.

보관 시간과 삭제 방식은 사이트마다 다릅니다. 사이트를 꼭 써야 한다면 개인정보 처리방침에서 '파일 보관 기간'을 먼저 확인합니다. 무료 사이트는 하루 횟수나 파일 크기에 제한을 두는 경우가 많고, 파일이 크면 올리고 내려받는 시간도 걸립니다.

맥: 설치 없이 바로 합치기

  1. Finder에서 합칠 PDF와 사진을 모두 선택합니다.
  2. 마우스 오른쪽 버튼 → 빠른 동작 → PDF 생성을 누릅니다.
  3. 같은 폴더에 합쳐진 PDF가 하나 생깁니다. 원본은 그대로 남습니다.

순서를 정하는 화면은 없으니, 원하는 순서가 있으면 파일 이름 앞에 01, 02처럼 번호를 붙여 둡니다. 쪽 하나하나의 순서를 바꾸는 미리보기 방법은 맥에서 PDF 합치기에 있습니다.

맥: 자주 합친다면 드롭핏(Dropfit)

드롭핏(Dropfit for Mac)은 제가 만든 맥 앱입니다. 화면에 떠 있는 동그라미의 'PDF'에 파일을 끌어다 놓으면, 순서와 파일 이름을 한 창에서 정한 뒤 PDF 하나로 합칩니다. 합친 파일은 첫 파일 옆에 저장되고, 파일은 맥 밖으로 나가지 않습니다.

PDF 합치기는 무료이고, 가입이나 횟수 제한 없이 사용할 수 있습니다.

윈도우: 인터넷 없이 동작하는 프로그램 고르기

윈도우에서는 PC에 설치해서 쓰는 PDF 프로그램을 고르면 파일을 올리지 않고 합칠 수 있습니다. 설치형이라도 일부는 합치기를 서버에서 처리하니, 처음 한 번은 와이파이를 끄고 합쳐 보면 확실합니다. 인터넷 없이도 합쳐지면 내 PC 안에서 처리하는 프로그램입니다.

합치기 전 확인할 것

  • 제출처의 용량 제한을 먼저 봅니다. 스캔본이나 사진이 많으면 합친 파일이 커지기 쉽습니다. 줄이는 법은 PDF 용량 줄이기에 있습니다.
  • 암호가 걸린 PDF는 먼저 암호를 풀어야 합칠 수 있습니다.
  • 제출처가 파일 이름을 정해 두었다면 합친 뒤 이름을 맞춥니다.

자주 묻는 질문

PDF 합치기 사이트는 안전한가요?

사이트는 파일을 서버로 받아 합친 뒤 돌려줍니다. 보관 시간과 삭제 방식은 사이트마다 다르니 쓰기 전에 개인정보 처리방침을 확인하고, 신분증·등본·계약서처럼 민감한 서류는 내 컴퓨터에서 합치는 편이 안전합니다.

PDF 병합과 PDF 합치기는 다른가요?

같은 작업입니다. 여러 PDF를 쪽 순서대로 이어 붙여 PDF 파일 하나로 만드는 것을 병합 또는 합치기라고 부릅니다.

맥에서 무료로 PDF를 합칠 수 있나요?

네. Finder의 빠른 동작 ‘PDF 생성’과 미리보기는 맥 기본 기능이라 무료이고, 드롭핏(Dropfit) 맥 앱의 PDF 합치기도 무료입니다. 세 방법 모두 파일을 인터넷에 올리지 않습니다.

내 프로그램이 파일을 올리는지 어떻게 확인하나요?

와이파이를 끄고 합쳐 보면 됩니다. 인터넷 없이도 합쳐지면 내 컴퓨터 안에서 처리하는 프로그램입니다.
