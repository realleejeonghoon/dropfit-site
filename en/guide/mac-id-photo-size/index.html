How to resize an ID photo to under 500 KB or 1 MB on Mac

November 2026 · macOS 14 or later

If your ID photo is over the size limit, open it in Preview on your Mac, choose File → Export, set Format to JPEG, and lower the Quality slider while watching the file size shown below it. If you have to meet the same limit again and again, an app that lets you set a target (for example, 500 KB) and just drop the photo is quicker. Neither method uploads your photo.

An application or government form says "max 500 KB" or "max 1 MB" for your photo. It's a picture of your face, so uploading it to some website to shrink it feels wrong.

First: check what the form asks for

  • File size: a limit such as 500 KB or 1 MB.
  • Format: usually JPG. iPhone photos (HEIC) and PNGs need converting.
  • Dimensions: if pixels or a ratio (such as 3:4) are specified, fix those before the file size.

1. Preview, by hand (free)

  1. Open the photo in Preview.
  2. Choose File → Export and set Format to JPEG.
  3. Move the Quality slider left and watch the file size shown below until it's under the limit.
  4. Save it under a new name.

You repeat this for every application, and going too low can blur your face, so open the result and check it.

2. Set the limit once: Dropfit for Mac

Every application had a different photo limit, and shrinking photos again each time got tiresome, so I built Dropfit for Mac.

  1. Control-click the circle on your desktop and, in Settings, make a preset with a maximum JPG size (for example, 500 KB).
  2. Drag the photo onto the circle and drop it on that preset. HEIC and PNG work too.
  3. A JPG under that size is saved next to the original. The original is untouched.

If it can't get under the size you set, Dropfit keeps the smallest version and tells you. If you need a set ratio, choose one such as 3:4, or Custom, in Crop.

FAQ

Can I shrink an ID photo on a Mac for free?

Yes. In Preview, choose File → Export, set Format to JPEG, and lower the Quality slider while watching the file size shown below it.

Can I use a photo I took on my iPhone?

Yes. Export it from Preview as JPEG, or drop it on Dropfit and the HEIC photo is saved as a JPG under the size you set.

Will shrinking the file ruin the photo?

Lowering the quality a lot can blur the outline of your face. Open the result to check it, and don't go far below the limit.
