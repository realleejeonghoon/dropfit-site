They can’t open your Pages or Keynote file? Send several as one PDF

November 2026 · macOS 14 or later

.pages and .key files don’t open directly on Windows PCs or Android phones, so the reply is often “I can’t open this.” On a Mac, open the document and choose Share → Export and Send → PDF in the toolbar, and anyone can open it. If there are several, export each to PDF and combine them so the recipient gets one file.

You email a proposal written in Pages and a deck made in Keynote, and the reply comes back: “The files won’t open. Could you send PDFs?” Most office and school computers run Windows, which has no Pages or Keynote. When the portal says “upload one PDF,” you also have to combine everything into a single file.

It happens to students who write on a Mac, freelancers and solo designers sending work to Windows-based clients, and job seekers who must submit their documents as one PDF. When the request comes right before a deadline, you end up exporting each document and putting them in order in a hurry.

1. Export each document to PDF (built into Pages and Keynote)

  1. Open the Pages document or Keynote presentation.
  2. Click the Share button in the toolbar, then click Export and Send.
  3. Choose PDF, click Save, and choose where to save it. The original stays as it is.

Numbers spreadsheets export to PDF the same way. If the recipient needs to edit the content, choose Word (Pages) or PowerPoint (Keynote) instead of PDF.

2. Combine the PDFs into one file (built into Finder)

  1. Select all the exported PDFs in Finder.
  2. Control-click and choose Quick Actions → Create PDF.
  3. A new single PDF appears in the same folder.

There is no screen for changing the order. If the order matters, add numbers like 01 and 02 to the start of the file names first.

3. If this keeps happening: Dropfit for Mac

Dropfit, a Mac app I built, doesn’t convert Pages files, but it shortens the combining step. Drag the PDFs onto the circle on your screen and drop them on PDF; after a window for setting the order, one file appears next to the originals. Merging PDFs is free.

If the combined PDF is over the upload limit, see PDF size limits for applications. Fitting a PDF under a size you set is part of Dropfit Pro.

Check before you send

  • A PDF keeps the layout fixed, so fonts don’t change and lines don’t shift. If the recipient doesn’t need to edit, PDF is the safest choice.
  • Adding a date or version to the file name avoids confusion if you’re asked to resend.
  • Keynote animations don’t play in a PDF. If motion matters, export to PowerPoint or a movie.

FAQ

Can I open a .pages file on a Windows PC?

Not directly, because Windows has no Pages app. If the recipient has an Apple Account, they can sign in at iCloud.com, click the More button on the file, and choose Download a Copy to get a PDF or Word file. The surest way is for the sender to export a PDF.

Can I send a Keynote file as PowerPoint?

Yes. In Keynote, choose Share, then Export and Send, then PowerPoint to get a .pptx file. Choose PowerPoint if the recipient needs to edit it, and PDF if they only need to view it.

Can I export many Pages documents to PDF at once?

Export in Pages and Keynote works one document at a time. You can batch it with AppleScript or Automator, but that takes setup. For a handful of documents, exporting each one and then combining the PDFs is faster.

Can Dropfit convert a Pages file to PDF?

No. Dropfit does not open Pages or Keynote files. Export the PDFs from Pages first, then use Dropfit to combine them into one file or fit them under a size limit.
