How to combine PDFs on Mac

November 2026 · macOS 14 or later

To combine PDFs on a Mac quickly, select the files in Finder, Control-click, and choose Quick Actions → Create PDF. If you need to arrange individual pages, use Preview. If you combine files often and want to set the order and file name in one step, a small app is quicker. None of these upload your files.

"Please send it as a single PDF" comes up all the time, and uploading a contract or an ID scan to a website just to merge it can feel wrong. Your Mac can do it without installing anything.

1. Combine in Finder (fastest)

  1. In Finder, select all the PDFs and images you want to combine.
  2. Control-click and choose Quick Actions → Create PDF.
  3. A combined PDF appears in the same folder.

There is no screen for changing the order. If the order matters, add 01, 02 and so on to the start of the file names first.

2. Arrange pages in Preview

  1. Open the first PDF in Preview.
  2. Choose View → Thumbnails to show the page list on the left.
  3. Drag the next PDF from Finder into that list, where you want it to go.
  4. Drag pages in the list to change their order.
  5. Choose File → Export as PDF and save it under a new name.

A plain Save changes the original PDF you opened. To keep the original, use Export as PDF.

3. Set the order and name in one step: Dropfit for Mac

I make Dropfit for Mac, a small app that sits on your desktop as a circle. Drag files onto PDF on the circle and they become one PDF.

  1. Select the PDFs and photos and drag them onto PDF on the circle.
  2. In the order window, drag files to reorder them or sort by name. The file count and total pages are shown at the top.
  3. Type a file name and press Return.
  4. The combined PDF is saved next to the first file.
  • Text and lines in your PDFs stay sharp; pages are copied as they are.
  • Each photo becomes one page, in its original orientation.
  • Leave the name empty and the file is named after the first file. Drop a whole folder and it is named after the folder.

Merging PDFs is free, with no sign-up and no limits.

Before you send it

  • If there is a size limit, select the combined file and press ⌘I to check its size. Scans and photos make PDFs large quickly.
  • Password-protected PDFs need to be unlocked before you can combine them.
  • For contracts and ID documents, combining on your Mac keeps them off other people's servers.

Questions

Can I combine PDFs on a Mac for free?

Yes. Finder's Create PDF quick action and Preview are built into macOS, and merging PDFs in Dropfit for Mac is also free.

Can I combine photos and PDFs into one file?

Finder's Create PDF and Dropfit for Mac both merge photos and PDFs into one PDF. Each photo becomes one page.

Does combining change my original PDFs?

Finder and Dropfit create a new file and leave the originals alone. In Preview, a plain Save changes the PDF you opened first, so use Export as PDF to make a new file.
