How to resize many photos at once on Mac (e.g. to 1080 px wide)

November 2026 · macOS 14 or later

There are two free ways to resize many photos at once on a Mac. Select them in Finder, Control-click, and choose Quick Actions → Convert Image with an image size (Small, Medium, Large), or open them all in Preview and use Tools → Adjust Size to enter a width in pixels. If you often need an exact width such as 1080 px, an app where you enter it once and save every photo is quicker.

iPhone and camera photos are often over 4000 px wide, so they upload slowly or hit size limits on blogs, stores and email. You can shrink them on your Mac without uploading them anywhere.

1. Finder Quick Actions (free, simplest)

  1. Select the photos in Finder.
  2. Control-click and choose Quick Actions → Convert Image.
  3. Pick a format and an image size (Small, Medium, Large or Actual Size), then convert.

New files appear in the same folder and the originals stay. You can't enter an exact number such as 1080 px, though.

2. Preview Adjust Size (free, exact pixels)

  1. Select the photos and open them in Preview.
  2. Click in the sidebar and press ⌘A to select them all.
  3. Choose Tools → Adjust Size, switch the unit to pixels and enter the width. Keep "Scale proportionally" on.
  4. Close the window; the changes are saved.

Preview saves over the originals, so duplicate them first if you need them.

3. Save at a set width: Dropfit for Mac

Dropfit for Mac is an app I built.

  1. Drag the photos onto the circle on your desktop and drop them on "Crop N images."
  2. In the Crop window, choose Custom and enter 1080 in the width box only. The height follows the ratio.
  3. Pick a format (such as JPG) and a maximum file size if you need them, then click Save.
  4. Every photo is saved 1080 px wide next to the original. The originals stay untouched.

To resize without cutting anything off, leave the frame as it is and save.

FAQ

Can I resize many photos at once on a Mac for free?

Yes. Select them in Finder and use Quick Actions → Convert Image, or select them all in Preview and use Tools → Adjust Size to enter a width in pixels.

Does resizing also make the files smaller?

Usually by a lot. If the site also has a file size limit, set a maximum size in Dropfit and the photos are saved under it.

What if some photos are portrait and some landscape?

With only the width filled in, each photo keeps its own ratio and is set to that width. If the long side must match, put the portrait photos in a separate batch and fill in the height instead.
