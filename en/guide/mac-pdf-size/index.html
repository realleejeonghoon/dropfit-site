How to reduce PDF file size on Mac (to 10 MB or 5 MB)

November 2026 · macOS 14 or later

The free built-in way to shrink a PDF on a Mac is to open it in Preview, choose File → Export, and set Quartz Filter to Reduce File Size. You can't set a target size, though, and photos can get blurry. If you have to meet a limit like 10 MB or 5 MB, an app that lets you set the target is quicker. PDFs with selectable text shrink a lot; scans, where every page is a picture, shrink less.

You put your application documents into one PDF and the upload form says "Max 10 MB." The usual next step is an online compressor, but uploading a file with your ID or employment details to an unknown server feels wrong. Your Mac can shrink it without uploading anything.

First: what kind of PDF is it?

  • Text PDF: you can select the text. Files saved from Word or Pages are like this. Most of the size comes from the photos inside, so they shrink a lot.
  • Scan: the text can't be selected. Every page is a picture, so there is a limit to how small it gets.

1. Preview Quartz filter (free, one file)

  1. Open the PDF in Preview.
  2. Choose File → Export and set Quartz Filter to Reduce File Size.
  3. Save it under a new name.

You can't set a target size and photos may get very blurry, so open the result and check it.

2. Hit a set size: Dropfit for Mac

Every form had a different limit, 10 MB, 5 MB, 2 MB, and shrinking files again each time got tiresome, so I built Dropfit for Mac.

  1. Control-click the circle on your desktop and, in Settings, make a preset with a maximum PDF size (for example, 10 MB).
  2. Drag the PDF onto the circle and drop it on that preset.
  3. A smaller PDF under that size is saved next to the original. The original is untouched.

What I measured:

  • A 12-page, 1.8 MB PDF with text and photos, set to 1 MB: about 130 KB. Text stays selectable and searchable.
  • A noisy 8-page, 42.1 MB scan, set to 10 MB: 7.1 MB, same page count.
  • The same scan set to 5 MB can't fit. Dropfit keeps the smallest version, 7.1 MB, and tells you: "Can't get under 5 MB (smallest 7.1 MB)."

For text PDFs, the text is kept and only the photos are recompressed. Your file never leaves your Mac.

If a scan must be under 5 MB

Rescanning at around 200 dpi is the reliable fix. Scans made at 300 dpi or more tend to blur the text whichever way you shrink them.

FAQ

Can I reduce a PDF's size on a Mac for free?

Yes. In Preview, choose File → Export and set Quartz Filter to Reduce File Size. You can't choose a target size, though.

Does compressing a PDF ruin the text?

Dropfit keeps the text of PDFs with selectable text and recompresses only the photos inside, so the text stays selectable and searchable.

What if it can't get under the size I set?

Dropfit keeps the smallest version it could make and tells you its size, for example "Can't get under 5 MB (smallest 7.1 MB)." The original stays as it is.
