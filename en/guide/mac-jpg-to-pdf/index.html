How to convert photos to PDF on Mac (many photos, one PDF)

November 2026 · macOS 14 or later

To turn several photos into one PDF on a Mac, select them in Finder, Control-click, and choose Quick Actions → Create PDF. iPhone HEIC photos work as they are. To check each photo and set the order, use Preview. To set the order and file name in one window, use an app. None of these upload your files.

You photographed a certificate or receipts with your phone, and the form says "Upload as a PDF." Now several photos need to become one PDF, and a converter website is not where you want your personal documents.

First: get the photos onto your Mac

AirDrop is fine, even if the photos arrive as HEIC. All three methods below turn HEIC photos straight into a PDF.

1. Finder Quick Actions: Create PDF (a few photos, fast)

  1. Select the photos in Finder.
  2. Control-click and choose Quick Actions → Create PDF.
  3. One PDF appears in the same folder.

There is no screen for changing the order. If order matters, put 01, 02 at the start of the file names.

2. Preview (check each photo)

  1. Select all the photos and open them in Preview.
  2. Drag the thumbnails in the sidebar to change the order.
  3. Select all thumbnails (⌘A), choose File → Print, then PDF → Save as PDF at the bottom left.

With many photos, this takes a lot of steps.

3. Order and name in one window: Dropfit for Mac

Dropfit for Mac is an app I built. I've had to combine photos of documents into one PDF for an application, then shrink it again because it was over the size limit.

  1. Select the photos and drag them onto PDF on the circle on your desktop.
  2. In the Merge PDF window, drag to reorder or click Sort by Name.
  3. Type a name and click Merge. One PDF is saved next to the first file.

You can mix photos and PDFs, for example adding a few photos after an existing PDF. Merging PDFs is free, with no account and no limits.

FAQ

Can I turn iPhone HEIC photos straight into a PDF?

Yes. Finder's Create PDF, Preview and Dropfit all make a PDF from HEIC photos without converting them to JPG first.

Can I choose the order of the photos?

Finder's Create PDF has no screen for the order, so number the file names. In Preview, drag the thumbnails. In Dropfit, drag in the Merge PDF window or click Sort by Name.

Can I convert photos to PDF on a Mac for free?

Yes. Finder and Preview are built into macOS and free, and merging PDFs in Dropfit for Mac is free too.
